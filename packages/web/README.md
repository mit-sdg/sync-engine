# @mit-sdg/sync-engine-web

`@mit-sdg/sync-engine-web/realization` realizes a named rendered interface as
Fetch claims. Rendering forms checked HTML fragments; this package owns the
opening document, retained field values, ask transport, and live refill stream.
Opening documents use `Cache-Control: no-store` because their holder identities
name process-local live resources and cannot be reused safely after a host
restart.
After a successful causal flow settles, a holder whose formed reads mention an
affected concept is reformed from its retained root invocation without rerunning
the endpoint. The realization derives addressed show, clause, and ordered-row
patches from consecutive formations. Identified rows move as their existing DOM
ranges; unaffected elements, fields, focus, selection, listeners, and widget
state remain in place. A query without row identity replaces only its authored
clause. Blank-line heartbeats keep an otherwise idle stream alive; the browser
reconnects with its last applied sequence and replays bounded patch history
after a transport interruption. If that history has expired, one root refill
repairs the holder. Changes settling during an active formation are
coalesced into a follow-up formation, which also covers newly encountered nested
reads. A slow stream is closed and recovers through the same current-value
catch-up rather than buffering patches without bound. This package does
not open a listener.
