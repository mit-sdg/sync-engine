# @mit-sdg/sync-engine-analysis

This repository-private preview provides deterministic static application
indexing, possible-impact tracing, and bounded context selection for
sync-engine tooling. It consumes a versioned application manifest and never
executes reactions or infers behavior from concept State prose.

The package is not published yet. It has no root export; its preview entrypoint
is `@mit-sdg/sync-engine-analysis/tooling`.

See [the candidate public surface](public-surface.md) for the exact API and its
analysis boundaries.
